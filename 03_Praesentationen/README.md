# Präsentationen

**Ablage nach Termindatum.** Pro Termin ein Ordner, benannt `JJJJ-MM-TT_Terminbezeichnung/`.
Darin die Präsentation und alles, was in diesem Termin gezeigt oder verteilt wurde
(Handouts, Screenshots, Demo-Notizen).

```
03_Praesentationen/
  2026-08-17_Discovery_Call/
      Discovery_Call_Biotec_CertoClav.pdf
  _unterminiert_Kick-Off/
      Odoo_KickOff_Biotec_CertoClav.pdf
```

## Regeln

- **Datum = Termindatum**, nicht das Erstellungsdatum der Datei.
- Noch nicht terminierte Decks liegen unter `_unterminiert_<Thema>/` und werden beim
  Festlegen des Termins in einen Datumsordner umbenannt/verschoben.
- Wird ein Deck für einen weiteren Termin überarbeitet, entsteht ein **neuer** Datumsordner.
  Der alte Stand bleibt unverändert – so ist belegbar, was wann gezeigt wurde.
- Dateiname im Ordner ohne Datum (das Datum steckt im Ordnernamen).
- Immer als **PDF** ablegen. Quelldateien (PowerPoint, Google Slides, HTML) gehören nach
  `06_Arbeitsdateien/`, wenn sie versioniert werden sollen.
- Das zugehörige Protokoll liegt in `02_Meetings/` mit demselben Datum im Namen.
